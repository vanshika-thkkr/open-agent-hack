
# Case Closed: an AI detective for café food waste

Open Agent Hackathon 2026, Track 02: The Agent That Can Explain Why. Solo project.

Café managers can see waste in their numbers, but not why it happened. Case Closed investigates, cites evidence for every claim, and rules out wrong suspects.

## How it works
1. **Zetaris (Lightning SQL)** queries synthetic café sales and waste data plus real Melbourne weather and holidays through one SQL layer.
2. **Screening battery**: code runs 5 fixed queries (overall waste, weekly outliers, rain effect, holiday effect, promo effect). Results become evidence E1 to E5.
3. **NVIDIA Nemotron via Meterless Nightshift** (nvidia/nemotron-3.5-lightning-30b-a3b) reads the evidence, may use up to 6 validated drill-down tools, and writes a CASE FILE: prime cause, suspects, ruled out, verdict.
4. **Meterless H-MEM** (Meterless Engine) stores verified findings with sources and recalls them on later questions. A finding is saved only if it cites evidence.

Evidence tables and SQL are generated by code, not by the model. If the model is unavailable, a plain evidence report is still produced.
